1. **ใน taxonomy ของเปเปอร์นี้ pipeline ของเรา = "Discrete Autoregressive" (§III-F) แต่ไม่มีตัวแทนของ tokenizer แบบ clustering** — นิยามใน §II-B.2b: discrete AR *"first transform continuous or structured data into sequences of discrete tokens, which is often achieved using vector quantization methods like VQ-VAE"* และ §III-F: *"typically via a VQ-VAE or related vector-quantization scheme"* · ⚠️ นิยามนี้ **ไม่ได้กีดกัน** k-means (k-means เองก็เป็น vector quantization แบบคลาสสิก) แต่ **ไม่มีเปเปอร์ไหนใน 16 ตัวของ Table VI ที่ใช้ และคำว่า k-means ไม่ปรากฏเลยทั้งเล่ม** → หนุนข้ออ้าง white space ของเรา (pillar 1) **ได้แค่ในฐานะ "survey ปี 2025 ไม่มีตัวแทน"** ไม่ใช่หลักฐานว่าไม่มีใครทำ (survey นี้ไม่ได้อ้าง Rhythm is a Dancer, Keyposes, Fan & An, ChoreoMaster ฯลฯ ที่ใช้ k-means เลย — ดู §11.1) · ⚠️ หมวด "discrete AR" ของ survey **ปน causal next-token (TM2T, T2M-GPT) กับ masked/bidirectional token model** (MoMask, MMM, LaMP, HGM³, MotionDreamer) → เวลาเขียนว่า "เราอยู่ตระกูลเดียวกับ §III-F" ต้องระบุว่าเราเป็นฝั่ง **causal**
   - ตัวเลขเดียวในเปเปอร์ที่หนุน "unconditional generation หายาก": Fig. 7 / Fig. 10 (p.25–26) คอลัมน์ conditioning = "none" มีแค่ **5 จาก 106 เปเปอร์** (Diffusion 2, VQ-VAE 1, Discrete AR 1, GAN 1; อ่านจาก heatmap Fig. 10)
2. **ไม่มีคำว่า LSTM, ไม่มี decoding strategy, ไม่มี exposure bias — แต่มี reference สาย RNN ที่ตามต่อได้** — string "LSTM" = 0 ครั้ง, nucleus/top-p/top-k/temperature = 0, exposure bias/scheduled sampling/teacher forcing = 0 → **ใช้เปเปอร์นี้หนุน R11-2 (Holtzman) / E8 ไม่ได้เลย** · อย่างไรก็ตาม reference list มีงาน RNN/LSTM ด้าน motion 3 ชิ้น: **[188] Zhou et al., *Auto-conditioned recurrent networks for extended complex human motion synthesis*, ICLR 2018 (acLSTM)** — ปรากฏเป็น dataset ของ Li et al. (car) ใน Table V (p.13) · [32] Fragkiadaki et al. 2015 (recurrent models for human dynamics; SIMPLE อ้างเรื่อง over-smoothing) · [96] Martinez et al. 2017 (RNN motion prediction) → **acLSTM [188] คือ lead ที่ตรงที่สุดสำหรับ R11-3/E9** (ความรู้ภายนอก ไม่ได้มาจาก survey: acLSTM ป้อน output ของตัวเองกลับระหว่างเทรนเพื่อแก้ error สะสมใน rollout ยาว ต้องอ่านต้นฉบับก่อนอ้าง)
3. **ประโยคเรื่อง error สะสม/drift/collapse ของ AR (ไม่มีตัวเลขรองรับในเปเปอร์):**
   - §III-C (VAE): one-shot non-autoregressive decoding *"eliminates cumulative error and enables direct length control"*
   - §III-C b) MultiAct: *"latent-space sampling can be repeatedly re-initialized without degradation"*
   - §III-D (VQ-VAE): discrete latent *"regularizes the representation and limits the accumulation of small reconstruction errors"*
   - §III-D a): Li et al. (vq) [75] ใช้ VQ-VAE prior + RL *"can alleviate drift and out-of-distribution failures that typically cause problems during autoregressive generation"*
   - §III-E c) RSMT (recurrent): *"carefully regularized to avoid collapsing to neutral motion"* ← failure mode ของ recurrent AR ที่ตรงกับความเสี่ยง LSTM ของเรา
   - §III-G c) SINN: *"maintains numerical stability over extended roll-outs"*
   - §III-K (INR): *"avoids cumulative error typical of frame-wise autoregression"*
   - §III-L b) PhysMoP: *"prevent drifting from the physically plausible solution over time"*
   → อ้างได้ว่า **"error สะสม/drift/collapse ของ AR เป็นปัญหาที่วงการยอมรับ"** และ **"การ discretize ถูกมองว่าช่วยจำกัดการสะสม"** แต่ต้องอ้างคู่กับ Bengio et al. (R11-3) / acLSTM [188] สำหรับกลไก และทำ E9 เองสำหรับตัวเลข
4. **§V ไม่ให้สูตร metric เลย** — ให้แค่นิยามคำเดียวบรรทัดเดียว (เช่น Coverage *"using nearest-neighbor thresholds in a feature space"*) → **ปิด E10 ไม่ได้** · ค่าจริงของ §V คือ **Table XIV = แผนที่ว่า metric ไหนใช้ในเปเปอร์ไหน** (Coverage ใช้ใน [34, 83, 92, 110, 150]; Inter/Intra Diversity ใน [34, 62, 110, 150]) → ใช้เป็นหลักฐานได้ว่า **ชื่อ metric ชุด SinMDM ที่เราเลือก (E7) ถูกใช้ต่อในงาน 2024–2025** (AnyTop [34], UniMoGen [62], VersatileMotion/MotionLLaMA [83], M³GPT [92], MotionDreamer [150]) แต่มี 3 ข้อควรระวัง: (ก) §V-G เองเตือนว่า *"Diversity, while easier to quantify, is hindered by inconsistent definitions, whether based on joint space, embedding space, or sampling strategies"* → ชื่อเดียวกันไม่ได้แปลว่าสูตรเดียวกัน (ข) **[62] UniMoGen เป็นงานของผู้เขียน survey นี้เอง** (Khani, Rampini, Atherton, Roy; arXiv:2505.21837) = self-citation (ค) [34] AnyTop มาจากกลุ่มเดียวกับ SinMDM (Raab/Tevet/Bermano/Cohen-Or)

## 4. Background (§II) — ส่วนที่เกี่ยวกับเรา

### 4.1 Representation (§II-A.1)
- **Keypoint** `P_t ∈ R^{J×d}`, d ∈ {2,3} — *"lacks explicit encoding of skeletal constraints"* → ต้องระวัง kinematic ที่ไม่สมจริง (= ปัญหา bone length ของเรา → metric "Bone Length Error" [124] ใน §V-A.2)
- **Rotation** ∈ SO(3) — รักษาความยาวกระดูก แต่ non-Euclidean ทำให้ออกแบบ loss ยาก
- **Mesh (SMPL)** N = 6890 vertices, β ∈ R^10 (shape), θ ∈ R^{3K}, K = 24 joints, ใช้ LBS · AMASS ใช้ SMPL เป็นมาตรฐาน
- เรา = **keypoint 3D (33 landmark) แล้วแปลงเป็น angle feature** → ไม่ตรงหมวดไหนเป๊ะ ใกล้ rotation (มุม) แต่ไม่ใช่ SO(3) ต่อ joint

### 4.2 Data collection (§II-A.2) — 4 แบบ
(a) Marker-based MoCap (แม่นสุด แพง) · (b) Markerless multi-view RGB · **(c) Pseudo-labeled (ของเรา)** · (d) Human design (animator)

### 4.3 สูตรของ Discrete AR (§II-B.2b) — ตรงกับ `train_lstm.py`
- `p(z_q) = Π_t p(z_q^t | z_q^{1:t−1})`, loss `L_CE = −Σ_t log p(z_q^t | z_q^{1:t−1})`, inference ทีละ token แล้วใช้ decoder `x̂_t = D(ẑ_q^t)`
- Continuous AR (§II-B.2a): `x̂_t = f(x_{1:t−1})`, loss MSE → **นี่คือ E5 (continuous-baseline LSTM)**
- VQ-VAE loss 3 เทอม (reconstruction + codebook + β·commitment พร้อม stop-gradient) [145]

## 5. Autoregressive — §III-E (continuous) และ §III-F (discrete) ⭐ ส่วนที่ checklist สั่ง

### 5.1 Continuous AR (§III-E, Table V — 7 เปเปอร์)
ข้อดีที่ผู้เขียนอ้าง: *"naturally capture fine-grained temporal dynamics, offer extremely low inference latency, and allow the generator to be seamlessly steered online"*

| Method | Architecture | Condition | ประเด็น |
|---|---|---|---|
| MANN [172] | Linear | Action–Trajectory | Mixture-of-Experts + gating, quadruped |
| Action2Motion [42] | RNN | Action | Lie-algebra pose + conditional temporal VAE |
| Guo et al. (car) [40] | RNN | Text | text2length → text2motion (สุ่มความยาวก่อน) |
| IMoS [36] | Attention | Action–Poses | human–object interaction |
| RSMT [137] | Attn–Conv–RNN | Action–Poses–Time | in-betweening; *"carefully regularized to avoid collapsing to neutral motion"* |
| HMD-NeMo [5] | Attention–RNN | Action | VR head/hand 6-DoF → full body |
| Li et al. (car) [71] | Attention | Poses–Trajectory | foot-contact → กำจัด foot sliding; dataset มี [8] (Aristidou dance) |

### 5.2 Discrete AR (§III-F, Table VI — 16 เปเปอร์)
ข้อดีที่ผู้เขียนอ้าง 3 ข้อ: *"(i) operating in a discrete space removes the need to learn fine-grained geometric detail inside the generative model, (ii) it allows direct reuse of powerful NLP architectures, masking objectives, and hierarchical token schedules, and (iii) the symbolic representation is easily editable"*

- **Text-to-motion:** TM2T [41] (VQ-VAE + **GRU** translator — ใกล้เราที่สุดในเชิงสถาปัตยกรรม), T2M-GPT [173] (GRU → GPT), AttT2M [185] (body-part VQ-VAE), MoMask [38] (residual VQ + masked transformer), LaMP [77], HGM³ [53] (hierarchical VQ-VAE)
- **Action-conditioned:** PoseGPT [91] (บน 3D mesh)
- **Physics:** MoConvVQ [166]
- **Editing:** MMM [105], CoMo [50] (body-part pose codes + LLM)
- **Foundation models:** MotionGPT [55] (*"motion as a foreign language"*), MotionChain [56], M³GPT [92] (text + **music** + motion), MotionLLM [156], VersatileMotion [83]
- **Unconditional / minimal data:** **MotionDreamer [150]** — *"generating from a single demonstration. A codebook regularizer prevents collapse, while sliding-window masked transformers model both local patterns and inter-window transitions"* · dataset ใน Table VI = [51] Mixamo, [141] Truebones Zoo → เป็นคู่เทียบฝั่ง discrete ของ SinMDM สำหรับ corpus เล็ก (ยังไม่อยู่ในคลังเรา) · ⚠️ เป็น **masked** transformer ไม่ใช่ causal next-token → เทียบกับ LSTM ของเราแบบตรงตัวไม่ได้
- สรุปของผู้เขียน: *"discrete autoregressive frameworks evolve from modest GRU translators to sophisticated, multimodal transformers"*
- หมายเหตุชื่อ: ข้อความเรียก [83] ว่า "VersatileMotion" แต่ reference [83] (p.30) ชื่อ *MotionLLaMA: A unified framework for motion synthesis and comprehension* (Ling et al., arXiv:2411.17335) → ค้นได้ทั้งสองชื่อ

**ข้อสังเกตสำหรับเรา:** ทุกตัวใน Table VI ใช้ condition (text/action/audio/pose) ยกเว้น MotionDreamer (∅) → **ภายใน Table VI งาน unconditional discrete AR มีตัวแทนตัวเดียว** (ทั้ง survey มีงาน unconditional/minimal-data อื่นอีก เช่น Li et al. (vq) [75] ใน Table IV, MoDi [109] ใน Table VII, SinMDM [110] ใน Table VIII — รวม "none" 5/106 ตาม Fig. 10)

### 11.1 เทียบกับคลังที่สรุปแล้ว

### 11.2 ผลต่อ thesis ของเรา
1. **Related work:** ใช้วางตำแหน่ง "เราอยู่ในตระกูล discrete AR (§III-F) ฝั่ง causal next-token แต่ tokenizer ต่าง (clustering แทน learned VQ) และ sequence model เป็น LSTM ซึ่งไม่มีตัวแทนใน Table VI (ใกล้สุดคือ TM2T ที่ใช้ GRU)" + ตัวเลข unconditional 5/106
2. **Evaluation chapter:** อ้าง §V-G เพื่ออธิบายว่าทำไมไม่ใช้ FID/classifier-based metric และทำไมต้อง **เขียนสูตร Diversity ของเราเองให้ชัด** (§V-G: definitions ไม่สอดคล้องกัน) · อ้าง Table XIV เพื่อบอกว่าชื่อ Coverage / Inter-Intra Diversity / Bone Length Error / Jerk เป็น metric ที่วงการใช้จริง (ระวัง self-citation [62])
3. **Limitations:** ข้อมูลของเราเป็น pseudo-labeled (§II-A.2c: "may contain noise and inaccuracies")
4. **ห้ามใช้เปเปอร์นี้เป็นแหล่งของ:** สูตร metric, ตัวเลข dataset (ให้ไปเอาจากเปเปอร์ต้นทาง), ข้ออ้างเรื่อง decoding/exposure bias
